# EliteTelegramBridge — PocketMine-MP Plugin Notice

> [!NOTE]
> **Free Aternos Notice**: Aternos Free servers do **NOT** support custom `.php` plugin uploads or direct FTP access.
>
> If you are running on **Free Aternos**, you do **NOT** need to upload or configure this PocketMine PHP plugin. The EliteSMP Vercel Telegram bot and Web Dashboard query live server status, player counts, MOTD, and software version automatically via **Bedrock RakNet UDP Ping** (or HTTP query fallback) without requiring any server plugins.
>
> This plugin codebase is preserved strictly for self-hosted or VPS PocketMine-MP instances where custom plugin files can be uploaded.
